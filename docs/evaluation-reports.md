# หน้าประเมินและรายงาน

เมนูด้านซ้ายแยกประเมิน PA, ประเมินครูผู้ช่วย, สรุปผล PA, สรุปผลครูผู้ช่วย และคลังเกณฑ์ การเปิด `/evaluate` ไม่ส่งไปเชื่อมบัญชีอัตโนมัติ ผู้ใช้ยังต้องมีสิทธิ์จึงดูข้อมูลหรือบันทึกคะแนนได้

คะแนนเป็น radio (ติ๊กได้หนึ่งค่าต่อรายการ) และแสดงสรุประหว่างกรอก ผลของกรรมการแต่ละคนแสดงหลังส่งคะแนน ส่วนผลรวมที่แสดงให้ครูในฝ่ายบุคคลเห็นต้องผ่านการยืนยันเผยแพร่ของผู้บริหาร กรรมการภายนอกเห็นและส่งออกได้เฉพาะผลของตนเอง

PDF ดาวน์โหลดจากเบราว์เซอร์โดยตรง รองรับภาษาไทยและ A4 ไม่ส่งข้อมูลไปบริการสร้าง PDF ภายนอก รายงานใช้ผลและเกณฑ์รุ่นที่ถูก snapshot ในรอบ ไม่ใช่แบบเอกสารราชการที่รับรองโดย ก.ค.ศ.

## เกณฑ์ที่ต้องตรวจเทียบก่อนเปิดรอบจริง

- PA: โครงสร้าง PA 2/ส อ้าง ว9/2564 และ ว22/2564 ใน `templates.js` ยังต้องตรวจรายละเอียดระดับตำแหน่ง/วิทยฐานะและแบบที่โรงเรียนใช้ก่อนผู้มีสิทธิ์ยืนยัน
- ครูผู้ช่วย: โครงสร้าง ว19/2568 ยังมีรายการชั่วคราวและถูกบล็อกจากการยืนยันเป็นเกณฑ์พร้อมใช้ จนกว่าจะตรวจเอกสารทางการครบ รายการและเงื่อนไขเดิมไม่ได้ถูกแต่งเติมในการเปลี่ยนหน้าจอครั้งนี้
- โรงเรียนยังไม่แน่ใจว่ามีผู้ที่ใช้เกณฑ์เดิมตามบทเฉพาะกาลหรือไม่ ให้เลือกรุ่นเกณฑ์เป็นรายรอบ และห้ามเปลี่ยน snapshot ของรอบที่สร้างแล้ว
- ขณะพัฒนา เครือข่ายปฏิเสธ `circular.otepc.go.th` และ `otepc.go.th` จึงยังไม่สามารถรับรองรายการฉบับเต็มได้ โดเมนถูกเพิ่มใน environment draft เพื่อให้ผู้ใช้ review/save ก่อนตรวจเอกสารต่อ
